Enter the plant's external drivers once (irradiance, temperature, etc.). Each trained component predicts its own output and shows it on its block above. When one component's target column name exactly matches another component's input feature, the value is chained automatically — e.g. PV Field's predicted DC power feeds the Inverter. Every input's source is shown; unresolved components are flagged, never guessed.
Edit any component’s identity and its input parameters. Parameters are free-form key/value pairs — put ratings, nameplate data, sensor ranges, anything relevant to that component.

Upload .csv or .xlsx (first row = column headers). Files are read entirely in your browser — nothing is uploaded anywhere. Legacy binary .xls is not supported (can’t be parsed offline without a heavy library) — re-save as .xlsx or .csv.
This trains a real model in your browser by gradient descent, so the loss curve below is genuine. The models are deliberately simple (ridge-linear or a 1-hidden-layer network) — good for quick site-level estimates, not a validated engineering simulator. For continuous targets, “accuracy” is reported as R² (1.0 = perfect, 0 = no better than the mean); RMSE/MAE are in the target’s original units.
